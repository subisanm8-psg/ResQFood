# ResQFood 🍲

### Waste Food Redistribution Platform

ResQFood is a waste food redistribution platform that connects food donors, such as restaurants, hotels, and event organizers, with NGOs and people in need. It aims to reduce food waste by making surplus food easier to donate, collect, and distribute.

## Features

* Connects food donors with organizations that can redistribute surplus food.
* Helps manage available food donations.
* Supports coordination between donors and recipients.
* Promotes food waste reduction and responsible food distribution.

## Getting Started

Follow these steps to download and run the project on your computer.

### Prerequisites

Install the following before starting:

* [Git](https://git-scm.com/downloads)
* [Node.js and npm](https://nodejs.org/)
* [Visual Studio Code](https://code.visualstudio.com/) (recommended)

### 1. Clone the Repository

Open Terminal and run:

```bash
git clone https://github.com/subisanm8-psg/ResQFood.git
```

Navigate into the project folder:

```bash
cd ResQFood
```

### 2. Open the Project in VS Code

```bash
code .
```

Alternatively, open VS Code, select **File → Open Folder**, and choose the downloaded `ResQFood` folder.

### 3. Install Dependencies

In the VS Code terminal, run:

```bash
npm install
```

### 4. Run the Application

```bash
npm run dev
```

Wait for the terminal to display a local development URL, such as:

```text
http://localhost:5173
```

Open the URL shown in your terminal in your web browser to view ResQFood.

Keep the terminal running while using the application.
